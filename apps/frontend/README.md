# Frontend workbench

The Next.js workbench exercises historical Nurture project/run fixtures through
the explicitly started legacy host and the shared
`@willyu1007/web-workbench` UI kit. It is not served by the normal scenario
service runtime.

It is a scenario-specific development console, not a separate account/auth/product shell. Shared production dashboard, notification, deep-link, and admin surfaces remain owned by My-Chat.
